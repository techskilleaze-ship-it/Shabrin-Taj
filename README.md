# Shabrin Taj — Portfolio

Personal portfolio of Shabrin Taj Mahaboob Sherief, SAP SuccessFactors Employee Central Lead Consultant.

## Run locally
Open `index.html` in a browser. It is a single self-contained file — no build step.

## Deploy on GitHub Pages
1. Create a repo (e.g. `portfolio`) and push these files to the `main` branch.
2. Repo → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / root.
3. Site goes live at `https://<username>.github.io/portfolio/`.
